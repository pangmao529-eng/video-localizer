# 视频中文转韩文：云端处理交接记录

记录日期：2026-11-27。本文区分已实现功能、已观察结果和待验证方案，不代表全部中文替换已完成或成片已获用户验收。

## 当前结论

`0.2.0rc21` 已完成 MediaKit 对话字幕流程接入，并对 `1029简中 (9)` 的前 10 秒取得通过技术检查、通过限定区域视觉检查的候选结果。后续 20 秒含静态游戏 UI、技能说明和弹窗，现有 MediaKit `Text` 擦除结果仍有大量中文残留。尚无通过“全画面中文全部替换、韩文字号保持不变”验收的后 20 秒成片，也没有通过该标准的 30 秒拼接成片。

最新用户约束是只让云端模型根据提示词处理视频。Codex 不得自行计算修改画面、确定字框或字号、排版、擦字、绘字；把这些操作放到自有服务器运行也不符合这一约束。手工排版方案已被用户叫停，未据此完成渲染与验收。后续应围绕云端编辑提示词、接口适配及实际输出验证推进，不能继续执行历史的本机或自有服务器绘字方案。

## rc21 已实现与已验证范围

- 已接入 MediaKit 云端视频 OCR、精细字幕擦除、异步任务查询、独立配置及断点恢复；提供相应 MCP 入口。
- 已有的字幕制作链路会使用用户定稿译文做匹配，再由自有服务器回贴区域并绘制韩文，复用原音轨。这是历史实现，不属于最新要求的纯云端模型编辑流程。
- Seedance 2.0 的上传、服务器分段、任务提交与查询、结果下载及服务器拼接链路已存在。先前的网络超时处理区分了连接、提交和查询超时；提交结果不确定时保留断点，避免自动重复创建付费任务。该链路的存在不代表所有原片已生成成功，也不代表符合最新的纯云端约束。
- 旧混元实现已移至 `legacy/hunyuan/`，不进入当前安装包。
- rc21 记录的回归测试为 305 项通过；安装验证和直接 MCP 握手通过。桌面会话曾存在工具目录缓存未同步的限制，不能仅凭版本号判断当前聊天已发现全部新工具。

对应证据见 [rc21 验证记录](../validation/0.2.0rc21.json)。上述是该记录的结果，不是本次编写交接文档时重新运行的测试。

前 10 秒候选结果为 1280×720、30 fps、300 帧、10 秒，解码、尺寸、帧率、帧数、时长及原音轨检查通过。共替换 4 条韩语字幕。视觉检查包括全画面抽样，以及字幕区域的 300 帧检查；在检查范围内未发现可识别的中文残字或明显补丁边框，4 条译文与参考一致，抽样主体和背景未见明显漂移。

这一结果的边界是：全画面没有逐帧完整验收；字幕区域检查不能证明所有 UI 中文都已替换；没有记录用户最终认可，也没有实时播放验收。视频经过重新编码，不保证像素完全一致；“韩文字号逐处与原中文一致”尚未形成完整验收证据。MediaKit OCR 官方语言范围不含韩语，输出 OCR 不能独立作为韩文准确性或中文残留的最终判据。

## 后 20 秒的问题与暂停状态

后 20 秒的 OCR 产生了 398 条记录，包含复杂游戏 UI、技能弹窗，也出现将星形符号误识别为汉字的情况。OCR 条目不能直接当作全部需要替换的文字清单。

已观察的 MediaKit v5.6、`mode: "Text"` 全画面擦除结果清除了部分字幕，但大量静态 UI 标签及技能说明中文仍可见。因此当前问题不只是译文缺失或网络连接，而是擦除能力与这些画面内容不匹配。不能把该结果直接用于叠加韩文，否则会留下原文或形成重叠。

手工补框、调整字号和排版的路线已停止，相关准备不等于已交付功能；未完成该路线的最终渲染与验收。当前阶段不应将局部成功、云端任务成功状态或技术检查通过写成“所有中文已替换”。

## 官方云端方案调研

以下仅为官方文档核对；Seedance 2.5、Kling 4.0、Wan 2.7 的新编辑流程尚未在本项目完成接入和原片真实验证。表中约束为查阅时文档所述，调用时仍应核对账号权限及最新接口要求。

| 方案 | 官方接口与关键字段 | 适用范围及未解决的限制 |
| --- | --- | --- |
| MediaKit 精细字幕擦除 | `/api/v1/tools/erase-video-subtitle-pro`；`mode: "Text"`、`erase_ratio_location` | 提供文字检测与擦除，区域参数限定处理范围；没有自由提示词、指定韩文译文并按原字号重绘的完整视频编辑字段。不能承诺指定区域内所有游戏字都被擦除。当前原片已观察到漏擦。 |
| Seedance 2.5 | `POST /api/v3/contents/generations/tasks`；`content` 中包含文字提示和 `role: "reference_video"` 的视频；显式编辑字段为 `omni_reference_task_type: "edit"`，不是 `task_type` | 编辑模式要求输入视频 4–30 秒、`ratio: "adaptive"`、`duration: -1`，可覆盖本次 20 秒片段。支持韩语提示，但这是生成式视频编辑，不保证逐像素或逐字字体尺寸一致。输出帧率及短暂时长偏差需要验证；未确认有直接保留原音轨的专用开关。 |
| Kling 4.0 | `POST /omni-video/kling-4.0`；`contents` 包含 `type: "base_video"` 和 `type: "prompt"`；`settings.audio: "original"` | 编辑主视频支持 3–30 秒，具备原音轨保留选项；官方说明支持画面韩文生成。可作为整段编辑候选，但不保证密集 UI 全部替换或字号精确保持。输出帧率是否与本次原片 30 fps 一致，仍需单独核验。 |
| Wan 2.7 视频编辑 | 视频合成接口使用 `model: "wan2.7-videoedit"`、`input.prompt`、`input.media` 视频项；`parameters.audio_setting: "origin"`、`parameters.prompt_extend: false` | 支持提示词编辑及强制保留原音轨，关闭提示词扩写可避免自动改写用户指令。输入编辑视频为 2–10 秒，不能一次处理后 20 秒；分段与拼接也必须符合最新云端约束。韩语密集 UI 的准确替换和原字号保持仍待实测。 |

官方依据：

- MediaKit：[精细字幕擦除接口](https://docs.volcengine.com/docs/intelligent-processing/erase-video-subtitle-pro?lang=zh)、[视频 OCR](https://docs.volcengine.com/docs/intelligent-processing/video-ocr-guide?lang=zh)。
- Seedance 2.5：[创建视频任务接口](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)、[模型说明](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)、[提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)。
- Kling 4.0：[API](https://kling.ai/document-api/api/video/4-0)、[API 使用指南](https://kling.ai/document-api/api/usage-guide/kling-4-0)、[多语言画面文字能力说明](https://kling.ai/quickstart/kling-4-model-user-guide)。
- Wan 2.7：[视频编辑 API](https://www.alibabacloud.com/help/en/model-studio/wan-video-editing-api-reference)。

参考视频生成与原视频编辑应分别配置。普通参考模式主要依据素材重新生成，不应仅因提交了原视频就视为保真编辑。上述编辑模型同样没有提供“全部中文准确换成指定韩文且字号不变”的质量保证，必须以本次原片的实际输出判断。

已准备[前 10 秒提示词](2026-11-27/cloud-only-first10-prompt.txt)、[整段提示词](2026-11-27/cloud-only-full30-prompt.txt)与[54 条中韩定稿](2026-11-27/latest-user-reference.json)；提示词仍属于待验证输入。下一步需要在已有授权范围内选择可调用的云端编辑接口，完成请求适配，以原视频和用户定稿译文进行真实测试，保留请求、任务状态和结果证据。当前文档不声称已提交这些新模型的付费任务。

本次进度打包另完成 320 个唯一测试及 53 个 Python 文件语法检查，最终无失败、错误或跳过；受沙箱环回网络限制影响的 16 个方法使用相同代码提升权限重跑并通过。只使用合成素材和模拟 API，见[打包回归摘要](../validation/progress-2026-11-27-regression.json)。这不能替代原片成片验收。

提示词应明确覆盖对白、静态 UI、技能说明、弹窗及小字，保持原有逐字可见尺寸、位置、颜色、描边、出现时段、遮挡关系和切镜关系，并要求其他画面与原音轨保持原样。译文应逐项绑定用户定稿，缺失内容交由云端处理并进入核对；不得由 Codex 自行补译或手工绘制。

验收必须分别记录：全画面中文是否漏替换、韩文是否准确完整、字号是否与原文一致、运动与遮挡是否稳定、切镜是否串字，以及画面内容、时长、帧率和音轨是否符合要求。云端任务成功只证明接口执行结束。若结果不合格，应记录具体时间点和问题，再修改提示词交给云端重做，不以本机或自有服务器的手工擦绘作为补救。

只有后 20 秒及合并后的完整结果都经过相应检查，才能将本次目标记为完成。本文与配套提示词不包含凭据、个人绝对路径、私有服务地址、任务标识或临时下载链接。
